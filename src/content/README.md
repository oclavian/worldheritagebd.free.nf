# পোস্ট/প্যাকেজ ফাইল কাঠামোর সহজ নির্দেশিকা (Content Folders Guide)

এখানে প্রতিটি সেকশনের জন্য আলাদা আলাদা ফোল্ডার তৈরি করা হয়েছে যেন যেকোনো পোস্ট খুব সহজে আপডেট, এডিট বা ডিলিট করা যায়:

---

### 📂 ১. উমরাহ্ প্যাকেজ (`src/content/umrah/`)
- `package1.ts` -> ১৪ দিনের ইকোনমি প্যাকেজ
- `package2.ts` -> ১৪ দিনের ডিলাক্স ৪-স্টার প্যাকেজ
- `package3.ts` -> রমজান স্পেশাল ২১ দিনের প্যাকেজ
- `index.ts` -> সব প্যাকেজ একত্রে তালিকাভুক্ত করে। (নতুন প্যাকেজ যোগ করলে এই ফাইলে `import` করে এরিয়াতে যুক্ত করবেন)।

---

### 📂 ২. হজ্ব প্যাকেজ (`src/content/hajj/`)
- `package1.ts` -> ২০২৭ সালের হজ্ব প্যাকেজের বিস্তারিত তথ্য।
- `index.ts` -> হজ্ব প্যাকেজের ডেটা এক্সপোর্ট করে।

---

### 📂 ৩. এয়ার টিকিট (`src/content/air-tickets/`)
- `airlines.ts` -> পার্টনার এয়ারলাইন্সসমূহের তালিকা।
- `info.ts` -> এয়ার টিকিট প্রাপ্তির নিয়ম ও প্রয়োজনীয় কাগজপত্রের তালিকা।
- `index.ts` -> এয়ার টিকিটের সমস্ত ডেটা এক্সপোর্ট করে।

---

### 📂 ৪. ট্যুর ও ভিসা (`src/content/tours-visas/`)
- `tour1.ts` -> সৌদি আরব জিয়ারাহ ট্যুর
- `tour2.ts` -> দুবাই ও আবুধাবি ট্যুর
- `tour3.ts` -> মালয়েশিয়া ও থাইল্যান্ড ট্যুর
- `tour4.ts` -> কক্সবাজার ও সেন্টমার্টিন ট্যুর
- `index.ts` -> সব ট্যুর প্যাকেজ এক্সপোর্ট করে।

---

### 📂 ৫. গ্যালারি (`src/content/gallery/`)
- `item1.ts`, `item2.ts`, `item3.ts`, `item4.ts`, `item5.ts`, `item6.ts` -> প্রতিটি ছবির আলাদা ফাইল।
- `index.ts` -> গ্যালারির সব ছবি এক্সপোর্ট করে।

---

### 📂 ৬. রিভিউ ও মতামত (`src/content/reviews/`)
- `review1.ts` -> হাজী মোঃ রফিকুল ইসলামের রিভিউ
- `review2.ts` -> প্রকৌশলী তৌহিদ হাসানের রিভিউ
- `review3.ts` -> ড. নার্গিস সুলতানার রিভিউ
- `index.ts` -> সব রিভিউ এক্সপোর্ট করে।

---

### 📂 ৭. ব্লগ ও নির্দেশিকা (`src/content/blog/`)
- `post1.ts` -> উমরাহ্ নির্দেশিকা ব্লগ
- `post2.ts` -> হজ্ব প্রাক-রেজিস্ট্রেশন ব্লগ
- `post3.ts` -> এয়ার টিকিট বুকিং টিপস ব্লগ
- `index.ts` -> সব ব্লগ পোস্ট এক্সপোর্ট করে।

---

### 📂 ৮. এজেন্সির তথ্য (`src/content/agency/`)
- `info.ts` -> এজেন্সির নাম, ঠিকানা, ফোন নম্বর, ইমেইল ও সোশ্যাল লিংক।
